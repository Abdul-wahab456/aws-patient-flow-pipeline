# Hospital Patient-Flow Lakehouse on AWS

An end-to-end data pipeline on AWS that ingests synthetic hospital data (FHIR, generated by Synthea), processes it through a bronze / silver / gold medallion architecture, and produces patient-flow KPIs (length of stay, 30-day readmissions, admissions and discharges, ED volume).

**Status:** work in progress. See [PROJECT_PLAN.md](PROJECT_PLAN.md) for the design and [docs/](docs/) for a step-by-step write-up of each phase.

Full documentation (architecture diagram, data model, how to run, KPI screenshots, cost summary) will be added in Phase 9.
